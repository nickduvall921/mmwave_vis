Z-Wave packet capture

For Red Series VZW32-SN testers. This records the Z-Wave JS driver log through Home Assistant so the switch's target tracking frames, which Z-Wave JS doesn't pass on yet, can be decoded.

  1. On firmware 2.04 or later, set parameter 107 to 1 so the switch reports target positions.
  2. Press Start, then walk around in front of the switch for about 30 seconds.
  3. Press Stop, download the file and attach it to issue #42.
Idle.
Download

Z-Wave JS logging is raised to debug while capturing and put back afterwards. A capture stops on its own after 15 minutes. The file contains your Z-Wave network traffic, so look it over before sharing.
