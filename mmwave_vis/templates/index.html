Z-Wave packet capture

For Red Series VZW32-SN testers. This records the Z-Wave JS driver log through Home Assistant so the switch's target tracking frames, which Z-Wave JS doesn't pass on yet, can be decoded.

  1. On firmware 2.04 or later, set parameter 107 to 1 so the switch reports target positions.
  2. Press Start, then walk around in front of the switch for about 30 seconds.
  3. Press Stop, download the file and attach it to issue #42.

Z-Wave JS logging is raised to debug while capturing and put back afterwards. A capture stops on its own after 15 minutes. The file contains your Z-Wave network traffic, so look it over before sharing.

Zone tools

Detect automatically asks the switch to find fans, vents and curtains and add interference areas around them.

A backup holds this switch's detection, interference and stay zones and their names. Importing writes every slot, clearing any that are empty in the file.

Clearing, resetting, detecting and importing can all be undone with the Undo bar at the top of this tab.

On ZHA, press Sync after saving or running a tool to see what the switch stored.

This switch

Sends live positions so people show up on the map. Turn it on while you set up zones and off when you're done, since it adds Zigbee traffic.

If nobody shows up with it on, bind manuSpecificInovelliMMWave on the switch's Bind tab in Zigbee2MQTT.

If nobody shows up with it on, open the switch in ZHA and choose Reconfigure.

Detection

How small a movement counts. Lower it if fans, curtains or pets keep the room occupied; raise it if someone sitting still gets missed.

How long movement has to last before the room counts as occupied. Slower ignores brief blips, at the cost of the light coming on later.

How long the room stays occupied after nobody is detected. Short saves energy; long avoids the light going off on someone reading.

How long the switch keeps counting someone in a stay area after they stop moving. It's in steps of 50 ms: 20 is 1 second and 300 (the default) is 15 seconds.

Test hold time times how long the switch takes to report clear after you leave, and compares it with the hold time.

Sit still test checks you stay detected while sitting still, and offers a stay area where you sat if you don't.

Both follow the map, so keep the page open.

System

Changes are sent to the switch as soon as you make them.

If settings look out of date, open the device in ZHA and choose Reconfigure to restore the cluster binding.
